# Cineport — Entertainment Reimagined

> **"CINEMA IS JUST THE BEGINNING."**  
> Next-generation entertainment destinations where movies, food, nightlife, events and technology come together across India.

---

## 🌟 Overview

Cineport is a production-quality web platform faithfully built according to the 13-page Cineport Design Specification. It features original AI-generated commercial photography, a responsive design system, and full interactive user flows.

---

## 🚀 The 13 Recreated Pages

1. **Home (`/`)**: Hero destination showcase, quick booking search panel, 8 category ribbons, "More Than a Movie" experience cards, and "What's Happening Today" event carousel.
2. **Cinemas (`/cinemas`)**: Pan-India expansion network, live screen metrics, interactive map/grid view toggles, and cinema destination cards with `LIVE`, `COMING SOON`, and `PIPELINE` badges.
3. **Experiences (`/experiences`)**: Complete destination guide covering Cineport Cinemas, Cineport Food Hall, Locker Room Sports Bar, Tiyatro Live Performance Bar, Bokata Microbrewery, CelebU Karaoke Suite, Hello VR Park, and Events & Celebrations.
4. **Food & Drink (`/food-drink`)**: Signature Food Hall destination, live kitchens, specialty coffee roastery, and 6 restaurant concepts with interactive menus.
5. **Events (`/events`)**: 10 event occasion packages (Birthdays, Corporate, Private Screenings, Premieres, Live Sports, etc.) and 6 versatile venue spaces with capacity indicators.
6. **Partner With Us (`/partner`)**: Property partnership models (Development, Operating, Acquisition), 5-step lifecycle process, and an interactive property submission form.
7. **Investors (`/investors`)**: ₹250 Cr expansion thesis, 8 revenue engines platform, 3-phase growth roadmap, and confidential investor deck request flow.
8. **About (`/about`)**: Company background (Village Groupe / Premiere Outlet Malls Pvt Ltd), Vision, Mission, Purpose, and 5 foundational values.
9. **Cineport Club (`/club`)**: 7 core member privileges, 3 membership tiers (**Silver**, **Gold**, **Platinum**) with full feature matrix comparison, and member onboarding.
10. **Night Builder (`/night-builder`)**: Interactive experience planner allowing guests to combine Movie, Dining, Entertainment, and Nightlife with dynamic price calculations and instant itinerary passes.
11. **Careers (`/careers`)**: Culture, employee perks, 6 functional departments with live job openings, and direct role application modals.
12. **Stories / Newsroom (`/stories`)**: Press releases, multiplex launch updates, category filters, and media spotlight.
13. **Contact (`/contact`)**: 6 department inquiry channels, corporate headquarters info, pan-India presence map, and direct messaging desk.

## 🛠️ Technology Stack

- **Framework:** React 19 + Vite 6
- **Routing:** React Router v7
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide Icons & Custom Vector Brand Marks
- **Visuals:** Original AI-generated commercial lifestyle & architectural photography

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
